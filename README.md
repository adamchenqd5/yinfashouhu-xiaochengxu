### 如何使用

1. 下载本仓库
2. 用微信开发者工具导入 `dist/build/mp-weixin/` 目录
3. 确保 AppID 填写为 `wx12caf2c75b485ad2`
4. 点击"预览"即可

### 项目结构

```
src/
  pages/
    index/    - 首页（开始页面）
    select/   - 场景选择页
    chat/     - 聊天对话页（游戏核心）
  data/
    scenes.js - 诈骗场景数据
    rounds.js - 对话回合数据
```
