### 如何使用

1. 下载本仓库
2. 用微信开发者工具导入 `dist/build/mp-weixin/` 目录
3. AppID 填写 `wx03b9dcb19055f27d`
4. 点击"预览"测试，或点"上传"发布

### 分享功能

| 方式 | 说明 |
|------|------|
| 右上角菜单 | 点右上角 `···` → 转发给朋友 / 分享到朋友圈 |
| 首页按钮 | 首页底部 **"📤 分享给亲友"** 按钮，点击直接调起转发 |

### 项目结构

```
src/
  pages/
    index/    - 首页（开始页面 + 分享按钮）
    select/   - 场景选择页
    chat/     - 聊天对话页（游戏核心）
  data/
    scenes.js - 诈骗场景数据
    rounds.js - 对话回合数据
```
